# Benchmark Summaries

This directory retains concise, reviewable findings rather than raw logs, profiler dumps, test-result trees, or proprietary acoustic recordings. Git history preserves earlier detailed artifacts. New raw device output belongs under the ignored `build/benchmark-artifacts/` directory and should be summarized here only after classification.

| Summary | Scope |
| --- | --- |
| [`2026-07-28-initial-baselines-summary.md`](2026-07-28-initial-baselines-summary.md) | Emulator, initial Pixel 8a, acoustic, startup, resource, battery, and pre-remediation comparator findings |
| [`2026-07-30-phase-3-and-4-summary.md`](2026-07-30-phase-3-and-4-summary.md) | AudioTrack decision, render diagnostics, and early physical playback/lifecycle findings |
| [`2026-08-04-phase-8-qualification-summary.md`](2026-08-04-phase-8-qualification-summary.md) | Final TB-001–TB-018 qualification findings, limitations, and regression baseline |

Proprietary WAV files remain outside the repository. A summary may retain a checksum, recording setup, analysis method, and aggregate result without retaining the recording itself.
