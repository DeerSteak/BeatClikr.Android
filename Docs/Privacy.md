# Privacy

BeatClikr works offline and contains no advertising, analytics, tracking SDK, account system, or network permission. Songs, playlists, preferences, and practice history stay on the device except when Android performs an enabled system backup or the user explicitly shares a streak image or diagnostic report.

Diagnostic reports are generated locally on request. They contain app, device, Android, audio-route, stream-performance, typed failure-code, and recent playback-state metadata. They exclude song and playlist names, practice details, file paths, audio content, and persistent identifiers.
